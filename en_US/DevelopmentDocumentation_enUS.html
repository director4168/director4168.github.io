Development documentation



introduce

1. Code version

This site is based on front-end development of HTML 5, JS ES6 (ECMAScript 2015), and CSS 3 (Level 3). It is a purely static website, but hardly supports the IE series kernel


2. Available controls

Provide the following content:

  • Top bar (cancelled, but still available)
  • Main column (optional whether to include avatar)
  • Basic avatar (click to include animation, optional function)
  • Columns
  • Jump card (including animation)
  • Code box (with copy and highlight (based on highlight) functions)
  • Music play/pause
  • Pop-up window system (including animation)
  • Theme switching system (including animation)
  • Folding system (including animation)
  • Language switching system (a tag jump page)
  • Bottom Solid Plastic Button Hover System
  • ……

Starting from Index.html v26.05.13.2051, the theme memory function (located in the /CoreLogic.js theme switching module) is added. The memory is valid for ten minutes (10*60*1000). During the memory period, the memorized theme will be used directly instead of the browser theme.
